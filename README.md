# README Studio

A premium GitHub profile README generator. Build beautiful, customized profile READMEs with live preview, animated templates, and 80+ tech stack icons.

**[→ Open README Studio](https://takemygunq.github.io/readme-studio/)**

## Features

- **5 premium templates** — Pro, Minimal, Hacker/Terminal, Creative, Founder
- **80+ tech icons** — filterable by category, searchable
- **Live preview** — markdown source and rendered HTML side by side
- **GitHub Stats** — stats card, streak, top languages, trophy cabinet with 10 themes
- **Animated banners** — via Capsule Render, typing animations via readme-typing-svg
- **Profile view counter** — automatic badge
- **Download** — save as `README.md` with one click
- **Zero dependencies** — pure HTML, CSS, JS

## Quick Start

1. Open the studio and fill in your info
2. Pick a template and toggle the stats you want
3. Copy the markdown or download `README.md`
4. Create a GitHub repo named exactly `<your-github-username>`
5. Add the file and commit — your profile goes live instantly

## Local Development

```bash
git clone https://github.com/takemygunq/readme-studio
cd readme-studio
# open index.html in your browser — no build step needed
```

## Stack

Pure HTML · CSS Custom Properties · Vanilla JS  
External badge services: shields.io · capsule-render · github-readme-stats · streak-stats · readme-typing-svg
